Sistema gestores de contenidos

Historia

Los primeros sistemas de gestión de contenido o sistemas de gestión de contenidos fueron desarrollados por organizaciones que publicaron una gran cantidad de contenido en Internet y necesitaban actualizaciones continuas como revistas en línea, periódicos y publicaciones corporativas. En 1995 , el sitio de noticias tecnológicas CNET publicó su sistema de gestión y publicación de documentos y creó una empresa llamada Vignette , pionera de sistemas de gestión de contenidos comerciales. La evolución de Internet hacia los portales con más contenido y la alta participación de los usuarios directamente, a través de blogs y redes sociales, convirtió los gestores de contenidos en una herramienta esencial para internet, tanto para empresas como para instituciones y para personas. Los wikis sistemas y trabajo en grupo también son considerados CMS. Actualmente hay sistemas desarrollados en software libre y software propietario . En ambos casos, es necesaria una implementación para adaptar el gestor de contenidos al esquema gráfico y las funcionalidades deseadas. Para algunos gestores hay muchos modelos disponibles que permiten una simple implementación de la parte estética por parte de un usuario sin conocimiento de diseño. Los paradigmas de este caso son WordPress y Joomla , gestores sobre los que hay una gran comunidad de desarrolladores de extensiones (módulos, complementos, complementos , etc.) y modelos.

Definicion

Es una página web con algunas funciones de publicación. Tiene una interfaz administrativa que permite al administrador del sitio crear u organizar documentos diferentes. El gestor de contenido es una aplicación informática utilizada para crear, editar, gestionar y publicar contenidos multimedia multimedia en varios formatos. El gerente de contenido genera páginas web dinámicas que interactúan con el servidor web para generar la página web a petición del usuario, con el formato predefinido y el contenido extraído de la base de datos del servidor. Esto permite gestionar, bajo un formato estandarizado, la información del servidor, reduciendo el tamaño de las páginas para la descarga y reducción del coste de gestión del portal respeto de un sitio web estático en el que cada cambio de diseño debe realizarse en todos páginas web, al igual que cada vez que añades contenido debes hacer una nueva página HTML y cargarla en el servidor web.

Gestión de contenidos

Todo el Sistema de gestión de contenido realiza el siguiente proceso de gestión:

  • Creación de información. ES el proceso por el cual el usuario genera nueva información para poner la disposición del público. Puede generar información como texto, gráficos, imágenes, etc.
  • Presentación de la información
  • Publicación de la información
  • Mantenimiento de la información .- Es la actualización en la que puedes editar eliminar cierto contenido.
